Lesson 1

What is an agent?

An agent is a smart helper that can use tools to get things done.

Imagine a clever robot named Robo. Robo has learned a LOT and can answer many questions all by itself, like “What color do you get when you mix blue and yellow?” 🟢

But some things Robo just can't know from memory, like the weather today in your city, or how many books are in the library right now. Those things change all the time!

So Robo uses tools: special gadgets that go and fetch fresh answers or do real jobs. A helper that can use tools like this is called an agent. That's the big idea! 🎉

Lesson 5

Robo's recipe (pseudocode)

Pseudocode means writing the steps in plain words, like a recipe, before real code.

📝 How Robo answers a question
  1. WHEN a friend asks Robo a question:
  2. Robo READS the question carefully
  3. Robo THINKS: “Can I answer from memory, or do I need a tool?”
  4. IF a tool is needed → PICK the right tool, USE it, and READ what it gives back
  5. Robo SAYS the answer in a friendly way 💬
  6. Robo REMEMBERS the chat, so it can keep helping 🧠

Notice step 4 can repeat! Sometimes Robo uses one tool, gets the answer, and might need another tool. It keeps going until it has everything it needs. 🔁
